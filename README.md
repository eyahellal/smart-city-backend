# Smart City Management Platform — Backend

REST API backend for a citizen-government digital services 
platform, built during a professional internship at the 
Centre National de l'Informatique, Tunisia (Jan–Jun 2025).

## What it does
- Citizen incident reporting with real-time geolocation
- AI-powered support assistant (Google Gemini API)
- JWT-secured role-based access control (citizen / admin / agent)
- City-scale PostgreSQL database with optimised queries

## Tech Stack
Java · Spring Boot · Spring Security · PostgreSQL · 
Google Gemini API · JWT · Leaflet.js · OpenStreetMap/Nominatim
